# FED-Logo

Fingerabdruck mit @-Kern: die E-Mail als Spur, die sich eindeutig zuordnen lässt.

| Datei | Verwendung |
| --- | --- |
| `fed-logo.svg` | Logo, helle Hintergründe |
| `fed-logo-dark.svg` | Logo, dunkle Hintergründe |
| `fed-logo-mono.svg` | einfarbig (Druck, Stempel) |
| `fed-icon.svg` | App-Icon ab 48 px |
| `fed-icon-small.svg` | vereinfachtes App-Icon für 16–32 px |
| `fed-icon-<n>.png` | App-Icon 16 bis 1024 px |
| `fed.ico` | Windows (16–256 px) |
| `fed.icns` | macOS |

Farben: Dunkelblau `#14284B`, Blau `#2457C5` (dunkel: `#E6E8EC` / `#8AB0FF`).
Lizenz wie das Programm (GPL-3.0).
