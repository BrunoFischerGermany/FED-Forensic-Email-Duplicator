# OAuth einrichten (Google, Microsoft 365)

Die Anleitung ist ins Programm gewandert: **Einstellungen → Google / Microsoft 365 →
„Anleitung Microsoft“ / „Anleitung Google“**. Der Assistent verlinkt sie außerdem
bei fehlender Client-ID und bei Anmeldefehlern.

Quelltext der Anleitung (eine Datei je Sprache, wird im Programm angezeigt):

- Deutsch: [`src/fed/resources/help/oauth_de.md`](../src/fed/resources/help/oauth_de.md)
- English: [`src/fed/resources/help/oauth_en.md`](../src/fed/resources/help/oauth_en.md)

Weitere Sprachen: `oauth_<sprache>.md` daneben anlegen; fehlt eine Sprache, zeigt FED
die englische Fassung.
